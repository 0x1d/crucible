# athanor

athanor is a self-extending IDE: an NSH shell in the browser and a Bun API, with the alchemist agent writing components and services into it.

The documents conform to the [Formulary standard](https://github.com/0x1d/formulary). Every document has a fully qualified id that equals its path under `docs/`, prefixed with `crucible/athanor`.
